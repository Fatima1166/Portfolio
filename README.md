# Fatima Iqbal | Portfolio

3D portfolio built with plain HTML, CSS and three.js (loaded from cdnjs). Bundled with Vite.

## Run locally
```
npm install
npm run dev
```

## Build
```
npm run build
npm run preview
```

## Folder structure
```
Portfolio/
├── index.html                 page, styles and 3D scene
├── package.json
├── vite.config.js
├── .gitignore
├── README.md
└── public/                    copied as-is to the build
    ├── favicon.svg
    ├── cv/
    │   └── Fatima_Iqbal_Resume.pdf
    └── certificates/
        ├── DigiSkills_Full_Stack_MERN.pdf
        ├── Cisco_Data_Science_Python.pdf
        └── IBM_AI_Fundamentals.pdf
```

To update the CV, replace `public/cv/Fatima_Iqbal_Resume.pdf` and keep the same file name.
